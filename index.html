## 🚀 Cómo Usarlo 1. **Descarga o clona** este repositorio 2. Abre el archivo **`index.html`** en cualquier navegador 3. Escribe el **nombre del producto** 4. Selecciona la **fecha de caducidad** 5. Pulsa **"Agregar"** 6.
