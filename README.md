# 📦 PILAS — Control de Fechas de Caducidad

> Aplicación sencilla, práctica y autónoma para registrar, organizar y monitorear la caducidad de productos. Diseñada para uso personal, tiendas pequeñas o inventarios caseros.

---

## ✨ Características

- ✅ **Registro rápido**: Agrega productos con su nombre y fecha de vencimiento
- 🎨 **Código de colores**:
  - 🟢 **Verde** — Vigente (más de 120 días restantes)
  - 🟡 **Amarillo** — Próximo a vencer (120 días o menos)
  - 🔴 **Rojo** — Vencido (60 dias o menos)
- 💾 **Guardado automático**: Los datos se quedan guardados aunque cierres el navegador
- 📱 **Compatible con móviles**: Se ve bien en celular, tableta y computadora
- 🗑️ **Eliminar fácil**: Quita productos de la lista con un clic
- 🚀 **Sin instalación**: Solo abre el archivo `index.html` y funciona
